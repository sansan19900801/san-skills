# 对标分析 Skill

> 用五重过滤法寻找值得模仿的业务对标，排除主体差异造成的噪音。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

想找一个赚钱的生意模仿，但不知道该模仿谁、怎么判断值不值得模仿。这个 Skill 用五重过滤法帮你筛选：赚不赚钱、看不看得懂、能不能模仿、有没有"自我"干扰、有没有在纠结本质问题。

**注意：这是业务层面的对标分析（找赚钱的生意模仿），不是内容账号对标。**

## 你需要提供什么

- **必须提供**：你现在在做什么，或者你想做什么方向
- **可选提供**：你已经在关注的候选对标，或对标账号名称 / 主页链接（装了浏览器能力可自动读取公开内容）

## 你会得到什么

1. **五重过滤结果**：赚钱/看懂/能仿/排除自我/不讨论本质，逐项判断
2. **对标业务信息提取**：从公开账号内容里只提取和业务有关的部分（卖什么、价格阶梯、获客、转化、交付、复购、人群、公开经营信号），并标注来源
3. **商业模式拆解**：获客、转化、交付、复购的完整链条
4. **模仿路径**：第一步做什么、第二步做什么、第三步做什么
5. **模仿颗粒度检查**（如已有对标）：价格、包装、平台、内容形式、频率、标题风格等逐项对比

## 可选增强：让 AI 自动读取对标公开账号

默认情况下，你提供什么信息，AI 就基于什么分析。如果想让 AI 结合对标账号的公域公开内容做参考，分两步：

- **第一步（AI 来，你不用自己敲命令）**：跟 AI 说一声「帮我安装 browser skill」，它会用官方 GitHub 源直接装好：https://github.com/Tencent/BrowserSkill
- **第二步（需要你本人操作）**：在 Chrome 应用商店添加 BrowserSkill 扩展：https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi ；不会添加就直接问 AI，它会一步步引导你。

装好后，把要查的对标账号名称或主页链接发给 AI 即可。没有 Chrome 浏览器，推荐使用 Tabbit 浏览器或豆包浏览器安装本扩展。

> 不安装也可以：你手上有什么信息就给什么，AI 完全基于你提供的信息分析；给不了就算了，信息不足的部分不硬凑、不编造。

## 五重过滤

| 筛子 | 问题 |
|---|---|
| 1. 赚钱 | 利润至少是你当前收入的 10 倍 |
| 2. 看懂 | 能看懂获客、转化、交付、复购的完整链条 |
| 3. 能仿 | 你有能力执行他的流程（不依赖独家渠道/关系/资质） |
| 4. 排除自我 | 不讨论兴趣、偏好、经历——能干就干，不能干就换 |
| 5. 不讨论本质 | 不讨论行业前景、社会价值、红海蓝海 |

## 使用示例

```
我现在在做 AI 工具教学，帮我找一个值得模仿的对标
```

```
帮我分析一下这个生意值不值得模仿：[对标描述]
```
