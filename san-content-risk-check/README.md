# 内容发布风险检查 Skill

> 发布前逐句检查标题、正文、图片文字、字幕、口播、评论、账号资料的合规风险，给出具体位置和最小修改动作。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

写完内容准备发布，不确定有没有违规词、会不会被限流、哪里可能被平台拦截。这个 Skill 帮你在发布前排雷，找到具体哪句话、哪个画面有问题，以及怎么改。

**它不是让你删掉观点和锋芒**——强观点、情绪表达、个人风格都保留，只处理真正有风险的部分。

## 你需要提供什么

- **必须提供**：要发布的内容（标题+正文，或视频逐字稿，或图片）
- **最好提供**：目标平台（小红书/抖音/公众号等）、内容目的（个人分享/推广/接单/招聘）
- **可选提供**：配图/封面截图、账号主页截图、评论区内容

## 你会得到什么

1. **先说结论**：平台机器审核有没有明显触发点，内容本身有没有实质问题
2. **具体问题清单**：精确引用原句，说明问题机制和后果
3. **最小修改动作**：删什么、改什么、补什么，只改有问题的部分
4. **机器误伤提示**：如果正常内容可能被机器误判，会告诉你
5. **发布前确认**：哪些信息（资质、授权等）会改变结论
6. **视频贴片小字**（如需要）：真实准确的三行免责声明

## 两层检查

| 层级 | 检查什么 |
|---|---|
| 平台机器审核 | 广告结构、联系方式、外链、二维码、连续数字、敏感词面、OCR 噪声 |
| 内容实质风险 | 欺诈、虚假宣传、违规导流、医疗功效、侵权、隐私、攻击、危险行为 |

两层结论分别成立。机器误伤只写"可能触发机器审核"，不补造违规原因。

## 覆盖的风险类别

- 内容安全与公共风险（违法、诈骗、色情、暴力等）
- 网络访问与海外账号（翻墙、ChatGPT 等）
- 玄学占卜与封建迷信
- 轻度性暗示和变体辱骂
- 金融/医疗/教育培训受限推广
- 商业广告、招聘和接单
- 外链、联系方式和导流
- 宣传、价格和证明（绝对化用语、虚假承诺）
- 医疗健康美容食品功效
- 图片视频声音和账号资料
- 商业合作和协同营销
- 垃圾内容和机器误伤
