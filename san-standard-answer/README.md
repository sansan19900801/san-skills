# 理论挖掘与历史同构标准答案 Skill

> 给你的观点找到可信理论支撑，再用历史上结构相同的成功、失败、反例，提炼一个带适用条件的"标准答案"。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

你有一个观点、理论、方法或现实困惑，想知道：
- 哪个学科、哪位学者的理论能解释它？这个理论到底是谁说的、原意是什么？
- 历史上有没有人遇到过结构一样的问题？他们怎么做的，成了还是败了？
- 有没有一个经过验证、带适用条件的"标准答案"？

这个 Skill 固定做两件事：**理论挖掘**（找机制、核实来源）+ **历史同构**（结构指纹匹配案例，不是看谁名气像）。

## 你需要提供什么

- 一个理论、观点、案例、方法，或者一个现实困境
- 说明用途（研究 / 短视频 / 课程 / 文案 / 现实决策）

## 你会得到什么

1. **直接答案**：先回答，再展开
2. **命题审查**：你的说法是绝对化、因果跳跃还是经验普遍化（保留/收窄/重构/放弃）
3. **理论地图**：主理论 + 辅助理论 + 纠偏理论，每个都带核实状态
4. **历史同构**：成功、跨域重复、失败、反例四类案例 + 类比有效性矩阵
5. **主动证伪**：给结论前先尝试杀死它，找最强反例
6. **标准答案分级**：成熟共识 / 条件性答案 / 尚无统一答案，都带适用条件和失效边界
7. 需要时附 3 个短视频原型

## 三条路径（自动判断深度）

- **快路径**：事实性问题，只给答案
- **中路径**：问机制，给命题审查 + 主理论 + 边界
- **慢路径**：问"能不能成/历史上怎么做的"，完整两部分

## 防幻觉承诺

作者、著作、年份必须可确认，确认不了就标"待核实"，绝不编造学者和页码；理论名无法证实就只讲机制，不硬挂名人。

## 使用示例

```
我想用损失厌恶解释为什么人不敢辞职，还能解决哪些人的问题？历史上验证过吗
```

```
"长期主义"这个说法到底有没有理论依据，什么条件下成立、什么条件下是毒鸡汤
```

```
帮我把锚定效应做成 3 条短视频原型
```
