# 新手入门与 Skill 全目录

欢迎使用 san-skills。这是一份完整的使用手册，告诉你每个 Skill 是干嘛的、什么时候用、怎么用。

---

## 怎么开始

你不需要记住所有 Skill。两种方式：

### 方式一：用总控 `/san`（推荐）

直接说你的问题，`/san` 会帮你判断该用哪个 Skill。

```
/san 我最近做小红书，粉丝涨得慢，不知道问题出在哪。
```

总控会：
1. 读你的问题
2. 判断属于哪个领域
3. 推荐 1 个主 Skill + 最多 2 个辅助 Skill
4. 生成一段可以直接发送的提示词

### 方式二：直接调用具体 Skill

你知道该用啥的时候，直接调：

```
/san-content 帮我诊断一下这篇稿子的问题：……
/san-hook 优化一下这个开头：……
/san-diagnosis 我的商业模式有啥问题：……
```

## 使用技巧

### 1. 第一次用
直接输入 `/san 新手入门`，总控会带你走一遍。

### 2. 问题越具体越好
不要说"帮我看看内容"，要说"帮我看看这篇小红书笔记为什么没人点赞：[粘贴内容]"。

### 3. 做完一轮继续反馈
一个 Skill 输出结果后，如果你有新的想法或修改意见，直接说，再输入 `/san`，它会重新判断下一步。

### 4. 不用记命令
装了总控之后，你甚至不需要知道任何 Skill 的名字，说人话就行。

## 常见问题

**Q：总控会不会选错 Skill？**
A：大多数时候不会。如果选得不对，你直接说"这个不对，我要的是 XX"，它会调整。

**Q：可以同时用多个 Skill 吗？**
A：可以，总控会自动编排 1 个主 Skill + 最多 2 个辅助 Skill。

**Q：数据安全吗？**
A：所有 Skill 都在你本地运行，数据不上传第三方服务器。知识库功能也是读你本地的文件。

**Q：怎么更新？**
A：直接跟 Agent 说"更新 san-skills"就行。
