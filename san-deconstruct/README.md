# 概念拆解 Skill

> 用维特根斯坦语言哲学和奥派经济学方法，把模糊商业概念拆到原子级别，识别伪概念。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

商业世界充满了听起来很厉害但说不清楚的词：私域流量、IP 定位、知识付费、复利、赛道、壁垒……这些词在不同人嘴里意思完全不同，导致讨论和决策都建立在模糊的语言上。

这个 Skill 帮你把一个概念拆清楚：它到底是什么意思、谁在偷换概念、去掉这个词用大白话还能不能说清楚、它是有标准答案的问题还是只能在实践中解决的问题。

## 你需要提供什么

- **必须提供**：一个你想拆解的概念、术语，或者一句让你困惑的话
- **可选提供**：这个概念出现的上下文（谁在什么场景下说的）

## 你会得到什么

1. **你以为它是什么**：这个概念通常被怎么理解
2. **不同场景的使用方式**：谁在说、说的时候什么意思、差异在哪
3. **概念还原**：原始语境、核心属性、被扭曲的部分、适用边界
4. **大白话版本**：去掉这个词，用最直白的话说清楚
5. **Question 还是 Problem**：是有标准答案的问题，还是只能在实践中解决的问题
6. **一句话总结**：犀利收尾
7. **7 张表深度分析**（可选）：对复杂概念做完整的本体论拆解

## 核心方法

1. **维特根斯坦式审查**：意义即使用——一个词在不同人嘴里意思不同就是问题
2. **奥派经济学校准**：主观价值论、行动先于理论、价格信号验证（仅商业概念）
3. **Question vs Problem**：大部分商业问题是 Problem 伪装成 Question

## 适合拆解的概念

精准流量、私域流量、知识付费、内容变现、个人品牌、IP、人设、复利、壁垒、护城河、赛道、风口、红利、高客单价、LTV、复购率等。
