# 目标清晰化 Skill

> 把模糊愿望和目标整理成可行动、可检查的交付物，只追问真正影响执行和验收的信息。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

"我想做个人 IP""我要变得更好""帮我做个网站"——这些目标听起来清楚，但根本无法指导行动，也无法判断什么时候算完成。这个 Skill 帮你审计目标：哪些已经清楚、哪些是阻塞性缺口、哪些词只是空话。

## 你需要提供什么

- **必须提供**：你的目标或愿望（哪怕很模糊）
- **可选提供**：已有的约束（时间、预算、资源）、使用对象、期望的交付物

## 你会得到什么

1. **目标卡**：交付物、使用对象、范围规格、完成条件、排除路径、下一步
2. **阻塞性缺口**：如果目标还不能执行，只问一个最关键的问题
3. **模糊词审计**：哪些词"没有在做工"（删掉后交付物不变），哪些需要定界
4. **排除路径**：哪些方式"看起来完成但不算数"，防止自己和 AI 走捷径

## 核心方法

- **语义做工检测**：一个词只有改变了交付物、执行路径或验收结果，才算"在做工"
- **封死捷径**：定义目标时同时说明"不能通过什么方式完成"
- **最小提问**：只问会改变交付物或验收结果的问题，不问流程性问题
- **四种路径**：直接放行 / 补一个缺口 / 审计模糊愿望 / 手段-目的测试

## 使用示例

```
帮我审计一下这个目标：我想做个人 IP
```

```
我这个目标够清楚了吗：3个月内小红书涨粉1000
```
