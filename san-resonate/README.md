# 文稿共鸣诊断 Skill

> 用传播学与社会心理学理论诊断文稿能否打中目标受众。一次诊断只选一个主理论，每条结论都指向原文具体哪句话。

![文稿共鸣诊断](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

一套面向内容创作者的共鸣诊断 Skill。它不预测播放量，也不承诺内容一定火，而是用 5 个主理论和 3 个条件理论，检查文稿的核心主张是否清楚、共鸣机制是否被文字落实、问题出在哪一句，并给出具体到删除/压缩/强化/保留的修改动作。

## 解决什么问题

- 内容没流量、没戳中人，却不知道是共鸣机制的哪一环断了；
- 不想凭感觉判断「能不能火」，想要基于传播学、心理学的结构化诊断；
- 想知道具体哪一句话该删、该压、该强化。

它用匹配当前文稿的传播学与社会心理学理论，定位核心主张和共鸣机制分别落实到哪一句，给出删除 / 压缩 / 强化 / 保留的具体动作。它判断的是共鸣机制，**不预测播放量**。

## 核心原则

1. **一篇文稿只保留一个核心主张** — 多个主张并列时标记"核心被稀释"
2. **一次诊断只选一个主理论** — 辅助理论需要明确触发证据
3. **诊断必须指向原文** — 每条结论回答哪句话激活了什么机制、缺失在哪句
4. **区分文稿能力与平台结果** — 本 skill 判断共鸣机制，不预测流量

## 5 个主理论

| 理论 | 诊断什么 |
|---|---|
| 社会认同与自我分类 | 受众能否把自己识别为某个群体成员 |
| 情绪评价理论 | 文稿如何通过目标相关性、责任、确定性形成具体情绪 |
| 框架理论 | 文稿如何定义问题、解释原因、作出评价 |
| 使用与满足研究 | 受众为什么观看、收藏或持续关注 |
| 情绪激活与在线分享 | 实用性、趣味、惊奇和高唤醒情绪是否形成分享倾向 |

## 3 个条件理论（满足触发条件才用）

- 沉默的螺旋 — 涉及意见气候、孤立恐惧
- 认知失调 — 明确制造信念/行为/自我认知矛盾
- 两级传播 — 已知存在意见领袖或人际扩散链

## 5 种常见问题模式

1. **身份对象含混** — "大家、普通人、创业者"太宽泛
2. **框架缺少因果桥梁** — 给了结论没说问题怎么发生
3. **只有情绪标签** — 直接说"焦虑、愤怒"但没写出评价路径
4. **用途不清** — 受众不知道看完能用于判断、决策还是行动
5. **分享理由不足** — 有观点但缺实用价值、新奇或高唤醒情绪

## 输出内容

- 核心主张审查（主张列表 + 核心主张 + 目标受众 + 预期动作）
- 理论诊断（主理论 + 触发证据 + 机制状态：有效/弱/无效 + 缺失项）
- 具体改法（删除什么、压缩什么、强化哪句、保持什么、修改后骨架）
