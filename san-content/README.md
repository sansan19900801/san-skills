# 内容诊断 Skill

> 发布前的最后一道编辑。你只负责把初稿发过来，AI 自动完成形式匹配、四维诊断、一票否决和修复排序，直接告诉你能不能发、先改哪里。

![内容诊断](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

一套面向自媒体人的内容发布前诊断 Skill。它不是帮你写内容的代笔工具，而是一个严格的内容编辑——拿到你的初稿后，从文字洁癖、封面标题、表达效率、认知落差四个维度逐项检查，引用原文原句指出问题，给出 🟢 SHIP / 🟡 FIX / 🔴 BLOCK 的明确判定，并附上具体的辅助创作建议。

## 解决什么问题

- 初稿写完拿不准能不能发、应该先改哪里；
- 标题、表达效率、AI 味、认知落差，不知道是哪一项在拖后腿；
- 怕事实错误、标题党、合规问题、自相矛盾这类「一票否决」项被漏掉；
- AI 改稿反复挑新刺，越改越多、越改越乱。

它是发布前的最后一道编辑：四维诊断加一票否决，给出 🟢 能发 / 🟡 改完再发 / 🔴 别发 的明确判定和修复顺序，复检时只查上一轮的问题。**注意：它不负责从零代写内容。**

## 核心理念

### 你只需要提供 3 类信息

| 你提供什么 | 怎么提供 |
|---|---|
| **选题和形式** | 选题是什么？打算发图文、短视频、长视频、直播还是文章？ |
| **目标读者** | 写给谁看？他们已经知道什么、不知道什么？ |
| **初稿或内容计划** | 有初稿直接发全文；只有想法也可以先做形式匹配 |

没有初稿也没关系，可以先让 Skill 帮你判断选题适合什么形式、什么平台。但文字层面的诊断必须有初稿才能做。

### AI 自动完成其余诊断

- 自动匹配内容形式和发布平台
- 自动识别内容类型（观点类 / 教程类 / 种草类 / 测评类 / 故事类），调整诊断侧重
- 自动跑四维诊断，每个问题引用原文位置
- 自动检查一票否决项（事实错误、标题内容不符、合规风险、逻辑矛盾）
- 自动给出辅助创作建议和修复优先级：先改什么、再改什么、什么可选
- 复检时只查上次的问题，不无限挑刺

## 四维诊断

| 维度 | 查什么 |
|---|---|
| **文字洁癖** | AI 味、Emoji 堆叠、空洞排比、口头禅、废话词 |
| **封面/标题** | 吸引力、情绪、认知劫持、标题与内容是否匹配 |
| **表达效率** | 一句话能不能说清核心观点、有没有冗余包装、是否服务变现 |
| **认知落差** | 比同行好在哪、受众会不会觉得"这个我知道"、有没有反常识 |

诊断完成后，根据内容类型单独给出辅助创作建议（AI 工作流、第一步行动）。

## 判定标准

| 判定 | 含义 | 条件 |
|---|---|---|
| 🟢 **SHIP** | 可以发 | 没有 🔴 问题，🟡 问题不超过 2 个 |
| 🟡 **FIX** | 改完再发 | 没有 🔴 问题，但有 3 个以上 🟡，或有 1 个严重影响效果的 🟡 |
| 🔴 **BLOCK** | 别发 | 触发一票否决，或有 2 个以上维度是 🔴 |

### 一票否决（Veto）

以下问题无论其他维度多好，直接 🔴 BLOCK：

1. **事实性错误**：数据造假、引用错误、张冠李戴
2. **标题与内容严重不符**：标题承诺了正文没兑现
3. **合规风险**：医疗/金融/法律的违规承诺、绝对化用语、侵权内容
4. **内部逻辑矛盾**：前后观点打架，自己推翻自己

## 平台覆盖

| 平台 | 适合形式 | 特点 |
|---|---|---|
| 小红书 | 图文、短视频 | 内容平台，涨粉靠内容质量 |
| 抖音 | 短视频、直播 | 内容电商平台，变现靠投流 |
| 视频号 | 短视频、直播 | 社交推荐平台，传播靠社交链 |
| X/Twitter | 观点输出、thread | 文字平台 |
| 公众号 | 长文章 | 深度内容 |
| YouTube | 长视频、教程 | 深度内容和教程 |

## 快速开始

### 方式一：直接发初稿诊断

```text
使用 $san-content 诊断我的内容。

选题：搞流量的内容不容易赚钱，赚钱的内容没流量
形式：小红书图文
初稿：
（粘贴全文）
```

Skill 会自动识别内容类型，跑完五维诊断，输出诊断报告。

### 方式二：只有选题，先做形式匹配

```text
使用 $san-content 帮我看看这个选题适合怎么做。

选题：AI 时代的个人品牌还有没有机会
```

Skill 会先推荐形式和平台，等你有初稿后再做完整诊断。

### 方式三：改完复检

```text
使用 $san-content 复检，我按上次的建议改了：
（粘贴修改后的全文）
```

Skill 只检查上一轮的问题是否解决，不引入新问题，通过就告诉你"可以发了"。

## 诊断逻辑

```text
选题 + 初稿 / 内容计划
        ↓
确认内容类型，调整诊断侧重
        ↓
五维诊断（每个问题引用原文位置）
        ↓
完整性自检（确保所有问题一次找全）
        ↓
一票否决检查
        ↓
输出判定 + 修复优先级 + 第一步行动
```

## 五条核心原则

1. **文字洁癖是底线**：AI 写的内容被限流不是 AI 的问题，是用 AI 的人对文字没有洁癖。
2. **自媒体的本质是精神控制**：封面和标题的本质是认知劫持。
3. **内容好坏 = 投入精力 × 正确理解**：缺一不可，否则进入"内容差→没流量→以量取胜→内容更差"的死亡螺旋。
4. **先有产品后有内容**：内容是为产品服务的，不是为了自嗨。
5. **知识博主只有两个工作**：把事情搞清楚，把事情说清楚。

## 诊断原则

1. **一次性找全所有问题**：输出前自检，不允许第一次说 3 个问题、复检又冒出 2 个新问题。
2. **每个判定都有证据**：引用原文原句，不说空话。
3. **复检不挑新刺**：只查上次的问题是否解决，通过就放行。
4. **完成比完美重要**：诊断的目标是让内容"可以发"，不是让内容"完美"。
5. **只诊断，不代笔**：告诉你哪里要改、怎么改方向，但不帮你写。

## 安装方法

### Codex

```bash
git clone https://github.com/sansan19900801/sansan-content.git
cp -R san-content ~/.codex/skills/
```

安装后可直接输入：

```text
使用 $san-content 诊断我的内容。
```

### Claude Code

```bash
git clone https://github.com/sansan19900801/sansan-content.git
cp -R san-content ~/.claude/skills/
```

### 豆包 / WorkBuddy

```bash
git clone https://github.com/sansan19900801/sansan-content.git
cp -R san-content ~/.agents/skills/
```

### 其他支持 `SKILL.md` 的工具

把整个 `san-content` 文件夹放到对应工具的 Skills 目录即可。
