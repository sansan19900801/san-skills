# 小红书标题公式 Skill

> 从 75 个在小红书上验证过的爆款公式中匹配最适合的公式，生成定制标题并解释为什么选这个公式。你不是万能标题生成器，你是公式匹配器。

![小红书标题公式](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

一套面向小红书创作者的标题生成 Skill。它不是随便起标题，而是从 75 个经过验证的爆款公式中，根据你的话题和行业匹配 5-8 个最合适的公式，每个标题都能追溯到具体公式编号，并附上原始爆款案例和推荐理由。

## 解决什么问题

- 小红书笔记起不出有点击欲的标题；
- 凭感觉瞎起，不知道标题为什么有效；
- 想批量生成，还要知道每个标题背后的套路依据。

它不是万能起名器，而是从 75 个验证过的爆款公式里，按你的话题和行业匹配 5-8 个最合适的，生成可追溯到公式编号、附原始爆款案例和推荐理由的标题并给 Top 3；已有标题也能反查用了什么公式、用得对不对。

## 12 类心理触发器

| 类型 | 编号 | 核心机制 | 最适合 |
|------|---------|---------|-------|
| 认知冲突 | 1-6 | 打破已有认知 | 观点输出、科普、打破误区 |
| 好奇缺口 | 7-12 | 信息不对称焦虑 | 揭秘类、行业内幕 |
| 恐惧/损失 | 13-20 | 不点就亏 | 避坑类、警告类 |
| 身份代入 | 21-25 | "说的就是我" | 垂直人群、精准获客 |
| 数字锚定 | 26-32 | 降低认知成本 | 方法论、清单类 |
| 结果承诺 | 33-40 | 具体结果+时间 | 教程类、变现类 |
| 社会证明 | 41-47 | 案例驱动 | 经验分享、逆袭故事 |
| 争议/挑衅 | 48-55 | 制造站队感 | 观点类、评论区互动 |
| 场景/条件 | 56-60 | 精准匹配状态 | 解决方案类 |
| 行动号召 | 61-66 | 推动行动 | 态度类、行动指南 |
| 权威借力 | 67-71 | 名人/案例背书 | 方法论、案例拆解 |

## 工作流程

1. **理解输入**：确认话题和行业（只给一个就问另一个）
2. **匹配公式**：选 5-8 个最合适的公式，至少覆盖 3 种不同类型
3. **生成标题**：套入用户话题定制，标注公式编号，展示原始爆款，一句话解释
4. **输出**：按类型分组展示 + Top 3 推荐 + 公式类型说明

## 标题质量 5 条铁律

1. **留悬念，不说答案** — 看完标题还需要点进来吗？
2. **话题扩大，不缩窄** — 用普世词替换行业术语
3. **击中真实痛点** — 不是表象概念，是受众真正想要的
4. **张力至少 2 项** — 对比/数字/悬念/冲突/时间/结果，6 选 2
5. **≤ 20 字（含标点）** — 硬性规范

## 特殊处理

- **已有标题优化**：先判断用了什么公式，诊断选对了没、执行得好不好
- **只想浏览公式**：输出 12 类速查表
- **不确定话题**：问"你想让读者产生什么反应？好奇、焦虑、共鸣、还是想学方法？"
