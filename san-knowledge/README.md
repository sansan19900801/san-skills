# 文件夹知识库 Skill

> 不装数据库、不上传云端，把你现有的普通文件夹（含 Obsidian 库）变成 Agent 能稳定查找、收录、判版本、查健康的本地知识库。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

资料越存越多，AI 却找不到、分不清哪个是最新版、还可能凭摘要瞎答。这个 Skill 用一份「知识库导航」（SOURCE_OF_TRUTH.md）给 Agent 指路，回答时强制回到原始文件，并持续帮你收录、查重、排雷。

## 四件事

- **建**：给新文件夹或已有文件夹建立知识库导航
- **存**：新资料放到合适位置，处理重名、版本、来源冲突
- **用**：定位原始文件再回答，标注依据和时效；高价值结论可回存
- **查**：健康检查，含失效路径和三类深度 lint

## 核心能力

1. **导航只指路**：回答必须读原始文件，不凭摘要以讹传讹
2. **三类深度 lint**：
   - 孤儿文件——存了却没被任何导航收录
   - 陈旧权威——标着"最新版"但源文件早已过时
   - 近似重复——高度相似却没建立版本关系
3. **冲突不静默**：两个来源事实打架时，登记「待确认冲突」等你裁定，绝不擅自挑一个
4. **结论可复利**：高价值综合结论，经你同意才存成派生笔记并挂回导航
5. **Obsidian 适配**：识别 `.obsidian/` 库，用双链、尊重现有结构，不强行重排
6. **写入安全**：只读随便做，移动/覆盖/批量改必须先给预览、你确认才动
7. **导航瘦身**：分层治理防止导航膨胀成文件清单，改动前自动备份

## 明确不做

- 不装向量库/Embedding/RAG，不做本地语义检索引擎
- 不按 PARA 等固定框架重构你的目录
- 不上传文件、不改写原始资料正文

## 你需要提供什么

- 一个本地文件夹路径，以及你想做的动作（建 / 存 / 用 / 查）
