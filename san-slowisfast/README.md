# san-slowisfast · 慢就是快（慢方法诊断）

> 不鼓吹慢，只帮你找出**少数值得慢做的判断密集环节**，其余坚决快做。核心链条：慢方法 → 必要摩擦 → 判断 → 资产 → 复利 → 被 AI/SOP 放大的杠杆。判据一句话：**不能产出可复利资产的慢，只是慢。**

## 它解决什么

当你担心自己太急、老返工、用 AI 批量产出却"心里没底"，或想搭一套越做越轻松的长期积累方式时，帮你：

1. 审计当前做法在哪绕开了必要摩擦、有没有留下资产、下次会不会更容易（三项检测）；
2. 对称地分清**哪些环节该慢、哪些环节该坚决快/自动化**；
3. 给出具体的慢方法替代，并把每次"慢"固化成一张可复用的**资产卡**；
4. 多个候选时按"资产价值 × 杠杆"排序，只让你先做最值得的一件；
5. 用三个复盘问题定期验证慢方法是不是真在复利。

## 什么时候触发

- "我是不是太急了 / 为什么老返工 / 一直在做重复功"
- "这事该快还是慢？""帮我看看这个做法是不是走捷径"
- "我用 AI 批量做，但拿到结果说不清过程"
- 直接丢一个做法 / 流程 / SOP / 计划让它审

## 五条公理（判断的根）

1. **摩擦是信息**：绕开摩擦也绕开了判断（同源：刻意练习、反脆弱）。
2. **短期的容易就是长期的痛苦**：看着快的捷径常长期反噬。
3. **资产是复利的基础**：能调用过去的积累，AI 才发挥作用。
4. **消耗战 vs 复利游戏**：做完下次更容易才算复利。
5. **设计摩擦，不设计发现**：可以刻意手动，但别盯着"我要收获什么"。

## 该快还是该慢

| 值得慢做（尽量同时满足） | 坚决快做/自动化（命中任一） |
|---|---|
| 判断密集、摩擦里有信号 | 机械执行、几乎不用判断 |
| 能留下可复用资产 | 做一百遍也不长理解 |
| 构成你的差异化 | 可回滚、试错成本低 |
| 资产能被 AI/SOP 放大 | 不构成差异化，谁做都一样 |

## 诊断流程

接收场景（信息够直接审）→ 三项检测（摩擦/资产+杠杆/复利，文字分级）→ 该快该慢分流 → 慢方法推荐并只选一件 → 产出资产卡 → 输出诊断报告 → 给复利复盘三问。

## 与其他 skill 的分工

| skill | 分工 |
|---|---|
| **san-slowisfast** | 判断哪里该慢、把慢做沉淀成可复利资产（本 skill） |
| san-knowledge | 资产卡/素材库/对标库的长期沉淀处 |
| san-learning | 学新东西时判断哪里亲手慢练、哪里快速略过 |
| san-content / spread | 创作流程里区分"判断手动、执行提速" |
| san-chatroom | 拿不准时拉多视角争论该快该慢 |

## 边界与不做

- 不灌"慢慢来、享受过程"的鸡汤，不用慢为拖延背书；
- 不做人生各维度的大而全规划；
- 不建议所有事都手动，机械环节明确要求自动化。
