# 传播心理解码 Skill

> 分析一段内容"为什么能打动人、为什么有人愿意转发"，并推导出后续可以接着写什么。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

你发了一篇内容，数据不错，但说不清楚为什么好。或者你看到一篇爆款，想拆解它打中了什么。这个 Skill 用传播学和社会心理学理论，帮你把"感觉它火得有道理"变成"它具体激活了什么心理机制"。

## 你需要提供什么

- **必须提供**：一篇完整的内容（公众号文章、小红书笔记、短视频逐字稿都可以）
- **最好提供**：目标平台（抖音/小红书/公众号/B站）、目标受众
- **可选提供**：评论区反馈、数据表现（点赞/收藏/转发数）

## 你会得到什么

1. **主导机制**：这段内容主要靠什么打动人（身份认同/情绪/框架/实用价值/分享动机）
2. **情绪路径**：受众看完具体产生什么情绪，怎么形成的
3. **行为动机**：为什么有人看、有人收藏、有人转发（分开判断）
4. **后续选题**：2—3 个可以接着写的选题方向，每个标注切入角度
5. **置信度**：哪些判断有文本证据，哪些还需要评论区验证

## 5 个主理论

| 理论 | 解释什么 |
|---|---|
| 社会认同与自我分类 | 受众为什么觉得"这说的是我们" |
| 情绪评价理论 | 受众如何形成愤怒、焦虑、释然等具体情绪 |
| 框架理论 | 内容如何定义问题、归因和评价 |
| 使用与满足 | 受众为什么观看、收藏或持续关注 |
| 情绪激活与在线分享 | 什么驱动受众转发 |

另有 3 个条件理论（沉默的螺旋、认知失调、两级传播），满足触发条件才调用。

## 与 san-resonate 的区别

- `san-resonate`：稿子没共鸣，诊断问题出在哪（偏修复）
- `san-spread`：稿子已经有共鸣了，解码为什么有效、接下来写什么（偏延展）

## 使用示例
