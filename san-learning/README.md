# 交互式学习 Skill

> 把任意课题拆成连续的学习文章，根据你的反馈和自测结果动态调整深度、角度和节奏，带你定期复习、结业验收；也能从一篇好内容反推出"要学会这种认知该补哪些知识"。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

让 AI 教你学东西，常见两个毛病：一次倒给你一大堆、不管你懂没懂就往下讲；或者你说"懂了"它就信了，其实只是眼熟。这个 Skill 用「连续短文 + 主动回忆自测 + 反馈自适应 + 间隔复习」解决，是一套**异步连载、可随时回看的课程生产线**。

## 两种启动方式

- **路径 A · 直接报主题**：「带我学 X」，直接拆成连续课程。
- **路径 B · 从好内容反推**：丢来一篇你认可的文章/对话，它提取核心观点，按「理论基础 / 学科背景 / 方法论工具 / 实践经验 / 底层思维」五维反推背后知识体系，标清必修·重要·补充，并诚实标出"只能靠实战、读书补不了"的部分，确认一次目录就自动建课。

## 核心机制

1. **一篇一个能力点**：每篇写明"学完你应该能做到 X"，不贪多
2. **教学四件事讲透**：先制造疑问再给答案、一个例子讲透四层、踩着已知搭梯子、每个概念讲清"是什么/为什么/然后呢"，成段讲给人听，不堆要点符号
3. **主动回忆自测**：篇末 2-3 道合上书才能答的题，答案放下一篇开头，分辨真懂还是假懂
4. **三路反馈自适应**：快速自评（懂了/半懂/没懂）+ 想要的讲法（类比/例子/动手/图解）+ 自测对错，共同决定下一篇怎么讲
5. **间隔复习**：每 3-4 篇自动插一篇复习，串联前面、重测易错点（不搞复杂算法）
6. **结业闭环**：学完出总复习地图 + 结合你真实场景的综合应用任务，过关才算学会
7. **因材施教的起点**：轻量扫描当前项目，区分"你亲自写的（强证据）/AI 草稿（弱证据）/第三方材料（不算）"
8. **时间预算**：按你每次能学多久控制单篇篇幅，不套固定周期和字数

## 明确不做

- 不做"答不对就当场拦住、来回对话到会为止"的同步私教陪学（那是独立私教 skill 的职责）
- 不做题库系统、闪卡引擎、SM-2 间隔重复算法
- 不做 K12 应试辅导、不代写营销内容
- 不遍历你的项目、不读密钥等敏感文件

## 你需要提供什么

- 一个主题（路径 A）或一段好内容（路径 B）、每次能学多久；之后每篇读完做下自测、写句反馈即可

## 使用示例

```
每次 15 分钟，带我系统学一遍奥派经济学
```

```
我发你一篇文章，帮我反推要学会作者这套分析力该补哪些知识，然后建课
```

```
继续下一篇
```

```
这篇半懂，多举点例子，自测第 2 题没把握
```

## 产出结构

```text
学习课题/{课题名}/
├── 00-学习计划.md   # 目标、时间预算、知识基础、能力掌握追踪表
├── 00-知识地图.md   # 仅路径 B：反推出的知识体系与学习目录
├── 01.md、02.md …   # 连续正课，每篇含开场/能力点/正文/自测/反馈区
├── R1.md …          # 间隔复习篇
├── 99-结业验收.md   # 总复习 + 综合应用
└── assets/
```
