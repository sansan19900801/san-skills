# 执行力诊断 Skill

> 用阿德勒心理学框架诊断"知道该做什么但就是不做"的真正原因，给出信号对应的处方和最小行动。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

你知道该做什么，但就是拖着不做。你试过各种时间管理方法，但都没用。这个 Skill 不安慰你、不给你鸡汤，而是直接诊断你不行动的心理机制，然后给你一个 5 分钟内就能完成的最小行动。

**这不是激励工具，是诊断工具。**

## 你需要提供什么

- **必须提供**：你现在卡在什么地方，越具体越好
- **可选提供**：你已经尝试过什么、你"觉得"阻碍你的是什么

## 你会得到什么

1. **信号识别**：你属于哪种拖延类型（6 种信号）
2. **诊断**：不行动的真正心理机制（不是表面原因）
3. **处方**：针对你的信号类型给出具体行动方案
4. **最小行动**：一个 5 分钟内可以完成的动作，小到不可能失败

## 6 种信号

| 信号 | 表现 | 处方 |
|------|------|------|
| A 执行模拟器 | 反复问人"方案怎么样"但从不执行 | 停止模拟，今天只做第一个最小动作 |
| B 思考手淫 | 反复思考计划但从不开始 | 给思考设 30 分钟截止，产出粗糙第一版 |
| C 方向跳跃 | 每个方向做不到 2 周就换 | 冻结当前方向至少 30 天 |
| D 知识上瘾 | 不停学课看书但不产出 | 暂停学习，用已有知识产出一个东西 |
| E 完美主义 | 因为不够好而不开始 | 30 分钟内做一个"烂版本" |
| F 被强迫叙事 | 归咎于外部条件 | 课题分离，只行动能控制的部分 |

## 使用示例

```
我想做小红书想了两个月了，看了很多教程但一篇都没发
```

```
我每天都在想该做什么产品，但三个多月了什么都没做出来
```
