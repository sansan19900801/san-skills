# san 总控问题与行为契约

反复出现的问题：用户不知道应使用哪个已经升级的 san 子 Skill，简短目录容易漏选、错选，或直接回答而跳过专业方法。

使用情境：在可读取本套件文件的 Agent 中提出一个真实业务、内容、学习或概念任务。

用户想推进的变化：通过与 dbs 一致的筛选、单项或主辅组合规则，找到合适的能力，再自主发送执行提示词。

交付：一个推荐（或一个主项加至多两个必要辅助）、理由、一段可发送的提示词；本轮结束。

完成证据：候选真实存在；输入、阶段、交付和权限匹配；读取入选规则；没有提前产生业务结果或工具写入。

不处理：总控本身不执行子 Skill 的诊断、创作或外部操作；不负责图片生成引擎、模型账户配置、sān UI 或在线发布。

允许变化：措辞、选择理由、合法的辅助组合随上下文变化。用户已经指定匹配子 Skill 时不重新要求重复背景。

关键失败：推荐不存在的能力、绕过确认、指定旧版路径、固定长链、因简单关键词选错。

验证说明：样本的 expected_behavior 只给评分者。当前对话已经读过这些标准，不能以本对话的试答冒充盲测。后续独立执行者只读取 prompt 和必要文件。
