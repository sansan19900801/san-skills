# 个人决策系统 Skill

> 把需要长期跟踪的业务、职业、关系、投资决策，建成本地 Markdown 决策档案：立案当下补齐关键信息，结果出来后校准你的判断力。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

做过的决定当时觉得想清楚了，三个月后既不记得当初为什么选、也不知道自己判断对没对；同类错误一犯再犯。这个 Skill 把决策变成一套可追溯、可校准的本地知识工程，而不是聊完就丢的对话。

## 四层档案结构

| 层 | 放什么 | 规则 |
|---|---|---|
| 01_事实 | 发生过什么 | 只追加 |
| 02_规律 | 从多次事实炼出的模式、判断力偏差 | 只追加修正，不重写 |
| 03_定格 | 某时整体快照 | 写完不改 |
| 04_待解 | 开放问题、假设、决策事件 | 解决即清，回流上层 |

## 核心特点

1. **按可逆性分流**：可逆决策快速试、轻量立案；不可逆决策必须先补齐备选方案、事前验尸、事前置信度才立案
2. **决策当下补齐 5 栏**：备选（含"不行动"选项）、事前置信度、事前验尸（最可能失败 vs 最致命失败）、复盘约定
3. **判断力校准**：回填时对比"事前置信度 vs 实际结果"，累计 3 次同类偏差就沉淀成"我在哪类事上系统性乐观/悲观"的规律
4. **防止篡改记忆**：事前置信度写下即冻结，绝不许用后见之明回改
5. **到期提醒**：自动扫描到了该回填却沉底的决策
6. **隐私模式**：人名/商业机密用代号，映射表不提交

## 你需要提供什么

- 初始化：这个决策域是什么、落盘位置、是否开隐私模式
- 日常：最近的变化、要立案的决定、后来的结果

## 五种模式

初始化 / 更新当前状态 / 决策立案 / 结果回填+校准 / 阶段快照

## 使用示例

```
帮我建一个"副业方向"的决策档案
```

```
我决定停掉图文 all-in 短视频，帮我立案
```

```
两个月到了，8 条视频最高播放只有图文一半，回填一下，看看我当初判断错在哪
```

## 安装

```bash
npx skills add https://github.com/sansan19900801/sansan-decision --skill san-decision -g --copy
```

默认落盘在 `~/.sansan/decisions/`，加 `--here` 落在当前目录。
