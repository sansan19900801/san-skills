# 逻辑延续检查 Skill

> 检查短视频逐字稿的段落衔接、信息密度和口播流畅度，定位观众会在哪一秒划走。完播率的敌人不是内容差，而是某一个瞬间观众跟不上了。

![逻辑延续检查](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

一套面向短视频创作者的文稿流畅度检查 Skill。它把逐字稿按段落拆分，从逻辑衔接、信息密度、口播流畅度三个维度逐段扫描，标注 🔴高风险/🟡中风险/🟢小建议，引用原文给出具体修复建议。检查完可以选择标记式改稿——用删除线和 🆕 在原文上原地标注改动，永不抹除你的原文。

## 解决什么问题

- 口播稿念起来卡顿、段落之间跳，观众在某一秒突然跟不上就划走；
- 不知道哪里信息密度掉了、在重复绕圈；
- 想直接在原文上标注改动、保留原稿不被覆盖。

它把逐字稿分段，从逻辑衔接、信息密度、口播流畅度三个维度逐段标 🔴🟡🟢，引用原文给出能直接念出口的修复建议，并支持删除线 + 🆕 的标记式改稿。只管「怎么说」，不改「说什么」。

## 观众划走的三个原因

| 原因 | 表现 |
|---|---|
| **逻辑断裂** | 前一段讲 A，下一段跳到 C，中间缺 B |
| **信息密度掉了** | 重复已说过的东西，或绕圈子 |
| **口播卡壳** | 句子太长、太书面、自问自答，念不出来 |

## 检查流程

1. **分段**：按话题切换点分段，标注段号、主题、功能（开场/铺垫/论证/案例/转场/高潮/结尾）
2. **逐段扫描三维度**：
   - 逻辑衔接：前后段之间有没有跳跃，缺不缺过渡
   - 信息密度：有没有重复、绕圈子、正确的废话
   - 口播流畅度：超 30 字单句、书面语、自问自答、未解释的术语
3. **标注风险等级**：🔴 高风险（大概率划走）/ 🟡 中风险（可能走神）/ 🟢 小建议（改了更好）

## 标记式改稿

检查完会主动问你要不要改稿。改稿时：

- `~~删除线~~` 标记建议删除的原文
- 🆕 标记新增/改写内容
- ⚠️ 标记 AI 撤回判断、还原原文
- 每个改动成对出现，原地操作，不写新版本贴底部
- 多轮反馈追加不覆盖
- 改完给改动清单表格 + 一句话优先级决断

## 注意事项

- 不改内容观点，只管"怎么说"不管"说什么"
- 修复建议必须口语化，能直接念出来
- 白板视频里的并列清单和"划重点"是视觉配套，不改
- 判断"跑题"前先问：删掉这段观众能不能自己脑补？脑补不出来就是必要的论证肉
