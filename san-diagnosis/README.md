# 商业模式诊断 Skill

> 不回答问题，消解问题。自动识别你是需要解决一个具体商业困境，还是需要全面体检商业模式。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 解决什么问题

你问"我适不适合做 XX""我的产品很好为什么卖不出去"——这些问题听起来需要答案，但大部分问题本身就是错的：用词没定义、假设不成立、逻辑有误。这个 Skill 先用五层漏斗消解假问题，让真问题浮现，再做诊断。

## 两种模式（自动识别，不用你选）

**问诊模式**：你有一个具体的商业困惑 → 走五层消解漏斗（语言陷阱→假设错误→逻辑错误→事实核查→信息不足），逐层对话，假问题在某一层直接消失。

**体检模式**：你想全面检查生意 → 七项检验（印钞机、道德、定价、需求、流量变现、规模化、成长层级），逐项对话讨论。

## 你需要提供什么

- 问诊：你的具体困惑和背景
- 体检：你卖什么、卖给谁、多少钱、怎么获客、怎么交付、月收入多少

## 你会得到什么

1. **风险速览评分表**：7 个维度 0-5 分，一眼看到哪里最危险
2. **七项检验详细分析**：逐项讨论，不是一次性甩报告
3. **失败链预测**：如果不改，最可能怎么死（根源→连锁反应→结果）
4. **7 天验证动作**：一周内能做完、能看到结果的具体实验
5. **止损线**：什么时间、什么指标没达到就转向
6. **反证问题**：要推翻这个诊断，你需要找到什么证据

## 核心哲学

- 商业模式是独立于人的客观机器，人只是喂料员
- 好模式逼你做好人，坏模式逼你做恶人
- 流量不等于收入，定价即产品
- 99% 的创业问题是心理问题
