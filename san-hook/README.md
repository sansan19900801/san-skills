# 短视频开头优化 Skill

> 诊断短视频前 5 秒的问题并生成 10-15 条优化方案。写不出好开头，90% 是因为内容本身有问题——开头是内容的试用装，内容不行再怎么优化开头也没用。

![短视频开头优化](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

一套面向短视频创作者的开头诊断 Skill。它不会在你内容质量不过关时强行优化开头，而是先检查内容完整性、素材丰富度和话题范围，通过后才用三种方法（素材提取、素材增补、悬念制造）生成 10-15 条开头候选，并给出 Top 3 推荐。

## 解决什么问题

- 短视频前几秒留不住人，开场就被划走；
- 不知道开头缺的是话题、钩子还是可信度；
- 想一次性要一批开头候选来挑。

它会先判断内容本身够不够格做开头（正文、素材、话题不过关会直接让你先补内容，不硬优化），再用素材提取、素材增补、悬念制造三种方法生成 10-15 条开头并推荐 Top 3。

## 核心公式

```
好开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```

## 四条信条

1. **开头是内容的试用装，不是标题的延续** — 必须在 5 秒内独立建立吸引力，不能假设用户看了标题
2. **好开头 = 话题 + Hook + 可信度** — 三者缺一不可
3. **开头要制造悬念，不要直接给答案** — 用"为什么"而不是"证明"
4. **开头必须口播友好** — 自问自答、书面语念不出口的都不行

## 诊断流程

| 阶段 | 检查什么 | 不通过怎么办 |
|---|---|---|
| 内容完整性 | 有没有正文？正文够不够 200 字？有没有价值？ | 停止优化，先把正文写出来 |
| 素材丰富度 | 有没有数据、转变故事、金句、权威背书、痛点共鸣？ | 5 个都没有→停止；1-2 个→效果有限 |
| 话题范围 | 不是这个领域的人会看吗？有没有缩窄人群的词？ | 太窄→警告，建议用更普世的切入点 |
| 当前开头 | 独立性、Hook、悬念、可信度、口播友好、匹配度 | 输出诊断报告 |
| 生成方案 | 素材提取 + 素材增补 + 悬念制造 | 共 10-15 条，Top 3 推荐 |

## 三种生成方法

| 方法 | 思路 | 优先级最高的 Hook 类型 |
|---|---|---|
| 素材提取 | 从文案中提取现有素材 | 晒结果+反转 ⭐⭐⭐⭐⭐ |
| 素材增补 | 主动补真实数据、案例、反常识结论 | 数据冲击、反差/转变 |
| 悬念制造 | 把结论改成问题 | 用"为什么"而不是"证明" |
